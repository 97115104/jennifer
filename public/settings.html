Gmail

How to get your Google credentials:
  1. Open Google Cloud Console and create a new project (name it "Jennifer" or anything)
  2. Go to Gmail API and click Enable
  3. Go to Credentials → Create Credentials → OAuth 2.0 Client ID
  4. If prompted, configure the OAuth consent screen first: External, add your email as a test user
  5. Application type: Web application
  6. Under "Authorized redirect URIs" add: http://localhost:3000/auth/google/callback
  7. Click Create — copy the Client ID and Client secret
  8. Paste them into .env as GOOGLE_CLIENT_ID= and GOOGLE_CLIENT_SECRET=, then restart Jennifer

GitHub

How to get your GitHub credentials:
  1. Go to github.com/settings/applications/new
  2. Application name: Jennifer
  3. Homepage URL: http://localhost:3000
  4. Authorization callback URL: http://localhost:3000/auth/github/callback
  5. Click Register application
  6. On the next page, copy the Client ID
  7. Click Generate a new client secret — copy it immediately (shown only once)
  8. Paste into .env as GITHUB_CLIENT_ID= and GITHUB_CLIENT_SECRET=, then restart Jennifer
